# Security and private information

This is an experimental local diagnostic, not an authentication service or a
production hosting server. Supported prototype code is the current `main`
revision with engine 0.1.20 and browser adapter 0.1.20-web.2. There is no security
response-time or maintenance guarantee.

**Do not put vulnerabilities, credentials, personal audio, customer material or
unreviewed reports in public issues.** If GitHub shows **Security → Report a
vulnerability**, use that private reporting form. If private reporting is not
available, open only a generic issue asking for a private reporting channel,
without technical exploit details or private information. Do not attach audio.

The local preview server is loopback-only and is not designed to be exposed to
the internet. Audio analysis stays in the browser; first-time runtime downloads
still contact the documented CDN. Review diagnostic reports before sharing them.
Do not assume that a public issue, a fork or a downloaded copy can be fully
erased later.
