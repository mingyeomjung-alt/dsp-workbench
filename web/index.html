Before you start
Which files should I compare?
Use a source WAV and the output produced by processing that source. A regression suite compares baseline and candidate outputs from the same source. Separate recordings and MP3 or M4A files are not supported.
Supported inputs
PCM16 mono WAV, 2–30 seconds, 8 / 16 / 44.1 / 48 kHz, up to 10,000,000 bytes per file. Each run allows 64 MiB of input and up to 6 regression cases. Files are not converted automatically.
How to read results
No temporal candidates means no possible deletions or adjacent repeats were observed within the supported scope. Review required means you should listen to the indicated regions and check whether the processing was intentional. Inconclusive and Cannot compare versions are not passing results.
Where do my files go?
Analysis runs in a Python Worker inside your browser. Only the runtime and example files are downloaded; selected audio is not sent to a server or saved in browser storage. Reports contain file hashes and diagnostic findings. Download them if you want to keep them.
What does a regression suite tell me?
New, persistent, and not observed now describe relationships between candidates in two results. They do not automatically confirm a fix, a quality improvement, or release approval. Check candidate observations separately from the current analysis state.
Running for the first time
The runtime download can take some time. A recent desktop browser is recommended. If memory is insufficient or Worker execution is restricted, the tool shows an error instead of treating the run as passed.
