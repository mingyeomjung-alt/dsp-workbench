검사를 시작하기 전에
어떤 파일을 비교하나요?
원본 WAV와 그 원본을 처리한 결과 WAV를 사용합니다. 회귀 검사는 같은 원본의 기준 버전 결과와 새 버전 결과를 함께 비교합니다. 서로 독립적으로 녹음한 파일이나 MP3·M4A는 대상이 아닙니다.
지원하는 입력
PCM16 모노 WAV, 2–30초, 8 / 16 / 44.1 / 48 kHz, 파일당 최대 10,000,000바이트. 한 번에 총 64 MiB, 회귀 검사는 최대 6사례입니다. 파일은 자동 변환하지 않습니다.
결과를 읽는 방법
후보 없음은 지원 범위에서 누락·인접 반복 후보를 관측하지 못했다는 뜻입니다. 검토 필요는 해당 위치를 직접 듣고 처리 의도를 확인해야 한다는 뜻입니다. 판단 보류와 비교 불가는 정상 판정이 아닙니다.
파일은 어디로 가나요?
검사는 브라우저 안의 Python Worker에서 실행됩니다. 실행 환경과 예시 파일만 내려받으며, 선택한 오디오를 서버에 보내거나 브라우저 저장소에 저장하지 않습니다. 보고서에는 파일 해시와 진단 내용이 담깁니다. 보관하려면 직접 내려받으세요.
회귀 검사의 의미
신규·유지·이번 미관측은 두 결과에서 관측한 후보의 관계입니다. 해결 여부·품질 개선·배포 승인을 자동 확정하지 않습니다. 후보 유무와 현재 검사 상태를 별도로 확인하세요.
처음 실행하는 경우
실행 환경 다운로드로 시간이 걸릴 수 있습니다. 데스크톱 최신 브라우저를 권장합니다. 메모리가 부족하거나 Worker 실행이 제한되면 오류를 안내하며 통과로 처리하지 않습니다.
